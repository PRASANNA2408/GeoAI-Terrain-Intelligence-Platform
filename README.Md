# AI-Based Landslide Susceptibility Mapping

## Overview

This project predicts landslide susceptibility using GIS datasets and Machine Learning.

## Objectives

- Process geospatial datasets
- Generate terrain features
- Train Machine Learning models
- Produce landslide susceptibility maps
- Build an interactive Streamlit application

## Technologies

- Python
- GeoPandas
- Rasterio
- Scikit-Learn
- Folium
- Streamlit
